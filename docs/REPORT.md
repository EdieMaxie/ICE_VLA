# 技术报告

## 基座模型

DM0.5，视觉-语言骨干 + 流匹配动作专家，三路 RGB 与本体状态条件，10 步采样输出连续
动作，6.15B 参数。

## 数据蒸馏

600 段 PiperX 数据逐帧校验后汇成语料。以基座为教师，固定噪声确定性采样取动作分布，
与真值配对，把多步生成压缩为单次前向可复现的监督；逐维归一化使不同相机与采样率保持
同一表征。

## 训练

LoRA r=32/alpha=16 注入全部线性子层，稠密微调动作投影与时间调制器，冻结基座。8 张
L40S，全局 batch 64，lr 1e-4，warmup 1000，余弦至 15000 步，可训练 324M。

## 部署

WebSocket 以 25 Hz 输出 50 步动作，异步预取下一块遮蔽推理时延；已提交前缀不变，块缝
施加关节连续性检查。
