# 技术报告

## 基座模型

基座为 DM0.5。该模型把视觉-语言骨干与流匹配动作专家统一在一个自回归-扩散混合架构中，
以三条 RGB 观测与本体状态为条件，经 10 步流匹配采样输出连续动作序列，具备开放指令跟随、
长时序任务与动态扰动下的闭环控制能力。全模型 6,153,393,584 参数，动作分块长度 50。

## 数据构建与语料蒸馏

我们从 LeRobot v3.0 的 600 段 PiperX 数据出发，经逐帧校验（帧序号连续性、14 维状态/
动作有限性、三相机对齐、任务描述非空）后，构建统一语料。蒸馏以基座为教师信号：对各
观测在固定噪声种子与确定性 10 步流匹配下取得动作分布，并与真实动作配对，从而把基座
的多步生成过程压缩成单次前向即可复现的动作监督；配合逐维归一化统计，使语料在不同
采样率与相机配置下保持一致表征，避免分布漂移。

## 训练方法

以 `r=32`、`alpha=16` 的 LoRA 注入全部线性子层，并对动作投影、time MLP 与时间调制器
进行稠密微调，冻结基座参数。在 8 张 L40S 上以全局 batch 64、学习率 1e-4、warmup 1000
步后余弦衰减训练至 15000 步。可训练参数 324,281,376，占 5.27%。

## 部署

评测侧以 WebSocket 暴露策略服务：25 Hz 输出 50 步动作，异步工作线程提前 16 步预取
下一块以遮蔽推理时延；已提交前缀严格不变，并在块缝处施加关节连续性检查，保证在线
执行的平滑与安全。
